## 자습과 수업 자료의 난이도 기준 통합

### 개요

학습자 자습과 직원용 수업 자료 생성이 같은 기준을 사용하고, 생성한 자료를 수업용 PDF로 재사용할 수 있도록 난이도와 저장 구조를 함께 설계했습니다.

**자습과 자료 생성의 공통 기준** 학습자는 수준에 맞는 수학과 읽기 활동이 필요하고, 직원은 수업 자료를 생성하고 관리해야 했습니다. 두 경로에서 난이도 기준을 공유하고 생성한 내용을 보존하는 것이 구현 과제였습니다.

### 세부 내용

**두 단계 난이도 적용** 수학과 읽기 자습, 직원용 코스 자료 생성에 같은 두 단계 난이도를 적용했습니다. 학습자가 활동할 때의 기준과 직원이 자료를 만들 때의 기준을 일치시켰습니다.

**코스 자료 저장과 PDF 재사용** 생성한 내용과 난이도, 운영 정보를 저장하는 코스 자료 데이터베이스 스키마를 설계했습니다. 저장된 자료를 수업용 PDF로 다시 활용할 수 있도록 구성했습니다.

### 성과

**하나의 기준으로 연결된 학습과 운영** 학습자는 두 단계 난이도로 자습하고, 직원은 같은 기준으로 수업 자료를 생성하고 관리하게 됐습니다. 생성한 자료를 저장해 PDF로 재사용하는 흐름까지 연결했습니다.
